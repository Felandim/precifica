## What shipped
- New tool: **Custo de embalagem no marketplace** → `custo-embalagem.html`
- Inputs: precoVenda (89), taxaMarketplacePct (16), custoProduto (35), fretePagoPeloSeller (12), custoEmbalagemUnit (3.5), vendasPorMes (200), metaMargemPct (15); optional breakdown caixa/fita/protecao/etiqueta (auto-sum)
- Math model (documented ESTIMATIVA):
  - `liquidoAposTaxa = precoVenda × (1 − taxaMarketplacePct/100)`
  - `custoVariavelSemEmbalagem = custoProduto + fretePagoPeloSeller`
  - `margemSemEmbalagem = liquidoAposTaxa − custoVariavelSemEmbalagem`
  - `margemComEmbalagem = margemSemEmbalagem − custoEmbalagemUnit`
  - `embalagemPctSobrePreco = (custoEmbalagemUnit / precoVenda) × 100`
  - `embalagemPctSobreMargem = margemSemEmbalagem > 0 ? (custoEmbalagemUnit / margemSemEmbalagem) × 100 : null`
  - `impactoMes = vendasPorMes × custoEmbalagemUnit` (= perdaMargemMes)
  - `tetoEmbalagemParaMargemZero = margemSemEmbalagem`
  - `tetoEmbalagemParaMetaPct = liquidoAposTaxa − custoVariavelSemEmbalagem − (precoVenda × metaMargemPct/100)`
- Badges: VERMELHO (inválido | margemComEmbalagem ≤ 0 | embalagemPctSobreMargem ≥ 40); AMARELO (embalagemPctSobreMargem ≥ 20 OU embalagemPctSobrePreco ≥ 5); VERDE (senão)
- Outputs via `calculateCustoEmbalagem`: `{ok, error, liquidoAposTaxa, custoVariavelSemEmbalagem, margemSemEmbalagem, margemComEmbalagem, embalagemPctSobrePreco, embalagemPctSobreMargem, impactoMes, tetoEmbalagemParaMargemZero, tetoEmbalagemParaMetaPct, badge, advice, disclaimer, copyText, …}`
- JS: `calculateCustoEmbalagem`, `badgeCustoEmbalagem`, `buildCustoEmbalagemAdvice`, `joinCustoEmbalagemCopy`, `mountCustoEmbalagem` on `[data-precifica-custo-embalagem]`; wired in `wireGlobalUi`; exported on API
