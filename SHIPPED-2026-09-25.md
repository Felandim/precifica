# SHIPPED 2026-09-25 — Prazo de repasse / float de caixa no marketplace (ferramenta)

## What shipped
- New tool: **Prazo de repasse / float de caixa no marketplace** → `prazo-repasse.html`
- Inputs: vendasPorDia (default example 8), ticketMedio (89), prazoRepasseDias (default 14 — ML típico; presets ML/Shopee/Amazon ou livre), taxaMarketplacePct (default 16), custoProdutoUnit (35), fretePagoPeloSellerUnit (default 12), percentualVendasParceladas (default 0), atrasoExtraParcelamento (default 0)
- Math model (documented ESTIMATIVA):
  - `receitaBrutaDia = vendasPorDia × ticketMedio`
  - `liquidoPorPedidoAposTaxa = ticketMedio × (1 − taxaMarketplacePct/100)`
  - `caixaSaidaPorPedido = custoProdutoUnit + fretePagoPeloSellerUnit`
  - `prazoEfetivoDias = prazoRepasseDias + (percentualVendasParceladas/100) × atrasoExtraParcelamento`
  - `floatReceber = vendasPorDia × prazoEfetivoDias × liquidoPorPedidoAposTaxa`
  - `floatJaGasto = vendasPorDia × prazoEfetivoDias × caixaSaidaPorPedido`
  - `necessidadeCaixa = floatJaGasto`
  - `diasAtePrimeiroRepasse = prazoEfetivoDias`
  - `margemPorPedido = liquidoPorPedidoAposTaxa − caixaSaidaPorPedido`
  - `margemDia = vendasPorDia × margemPorPedido`
- Badges: VERMELHO (inválido | margemPorPedido ≤ 0 | necessidadeCaixa > 60 × margemDia); AMARELO (prazoEfetivoDias ≥ 21 OU floatJaGasto > 30 × margemDia); VERDE (senão)
- Outputs via `calculatePrazoRepasse`: `{ok, error, receitaBrutaDia, liquidoPorPedidoAposTaxa, caixaSaidaPorPedido, prazoEfetivoDias, floatReceber, floatJaGasto, necessidadeCaixa, diasAtePrimeiroRepasse, margemPorPedido, margemDia, badge, advice, disclaimer, copyText, …}`
- JS: `calculatePrazoRepasse`, `badgePrazoRepasse`, `buildPrazoRepasseAdvice`, `joinPrazoRepasseCopy`, `mountPrazoRepasse` on `[data-precifica-prazo-repasse]`; wired in `wireGlobalUi`; exported on API
