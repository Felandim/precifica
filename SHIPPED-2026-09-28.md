## What shipped
- New tool: **Custo Full / fulfillment no marketplace** → `custo-full.html`
- Inputs: precoVenda (89), taxaMarketplacePct (16), custoProduto (35), freteEnvioProprio (18), custoFullUnit (14), armazenamentoMes (80), vendasPorMes (200), metaMargemPct (15); optional custoFullPct (se fee R$ vazio; se ambos, prefer absolute R$)
- Math model (documented ESTIMATIVA):
  - `liquidoAposTaxa = precoVenda × (1 − taxaMarketplacePct/100)`
  - `armazenamentoPorUnidade = vendasPorMes > 0 ? armazenamentoMes / vendasPorMes : 0`
  - `custoFullUnitResolved = custoFullUnit (prefer) OU precoVenda × (custoFullPct/100)`
  - `custoFullTotalUnit = custoFullUnitResolved + armazenamentoPorUnidade`
  - `margemSemLogistica = liquidoAposTaxa − custoProduto`
  - `margemEnvioProprio = liquidoAposTaxa − (custoProduto + freteEnvioProprio)`
  - `margemFull = liquidoAposTaxa − (custoProduto + custoFullTotalUnit)`
  - `deltaMargemUnit = margemFull − margemEnvioProprio` (positivo = Full melhor)
  - `fullPctSobrePreco = (custoFullTotalUnit / precoVenda) × 100`
  - `fullPctSobreMargem = margemSemLogistica > 0 ? (custoFullTotalUnit / margemSemLogistica) × 100 : null`
  - `impactoMesFull = vendasPorMes × custoFullTotalUnit`
  - `impactoMesEnvioProprio = vendasPorMes × freteEnvioProprio`
  - `economiaOuCustoExtraMes = vendasPorMes × deltaMargemUnit`
  - `tetoFullParaMargemZero = margemSemLogistica`
  - `tetoFullParaMetaPct = liquidoAposTaxa − custoProduto − (precoVenda × metaMargemPct/100)`
  - `freteProprioBreakEvenVsFull = custoFullTotalUnit`
- Badges: VERMELHO (!ok | margemFull ≤ 0 | fullPctSobreMargem ≥ 50); AMARELO (fullPctSobreMargem ≥ 30 OU fullPctSobrePreco ≥ 20 OU (deltaMargemUnit < 0 E |delta| ≥ 3)); VERDE (senão)
- Outputs via `calculateCustoFull`: `{ok, error, liquidoAposTaxa, armazenamentoPorUnidade, custoFullTotalUnit, margemSemLogistica, margemEnvioProprio, margemFull, deltaMargemUnit, fullPctSobrePreco, fullPctSobreMargem, impactoMesFull, impactoMesEnvioProprio, economiaOuCustoExtraMes, tetoFullParaMargemZero, tetoFullParaMetaPct, freteProprioBreakEvenVsFull, badge, advice, disclaimer, copyText, …}`
